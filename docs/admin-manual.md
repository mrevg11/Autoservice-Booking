# Посібник адміністратора — AutoService

## Доступ
Увійдіть за адресою `/login` з акаунтом ролі **ADMIN**.
Після входу ви потрапите на адмін-дашборд `/admin/dashboard`.

---

## Дашборд (`/admin/dashboard`)

Показує ключові метрики у реальному часі:
- **Всього клієнтів** / кількість майстрів
- **Записів сьогодні** / скільки очікують підтвердження
- **Дохід цього місяця** / загальний дохід
- **Середній рейтинг** по всіх майстрах

Також відображаються:
- **Графік доходу** по місяцях (LineChart)
- **Топ-послуги** (PieChart)
- Швидкі посилання: Користувачі, Послуги, Майстри, Записи

---

## Аналітика (`/admin/analytics`)

### Доходи
- Перемикач: День / Тиждень / Місяць
- Фільтр за датами (від / до)
- Лінійний графік: дохід + кількість записів
- **Кнопка "CSV"** — експорт поточного набору даних

### Завантаженість майстрів
- Горизонтальна гістограма
- Кольорова індикація: зелений < 50%, жовтий 50-80%, червоний > 80%
- **Кнопка "CSV"** — export

### Топ-послуги
- Pie chart + таблиця з кількістю записів та доходом
- **Кнопка "CSV"** — export

### Воронка статусів
- Гістограма конверсії: PENDING → CONFIRMED → IN_PROGRESS → COMPLETED → CANCELLED
- Відсоток від початкової кількості PENDING

### Утримання клієнтів
- **Нові** (перший запис < 30 днів тому)
- **Постійні** (2+ записи)
- **Відтік** (остання активність > 90 днів)
- **Серед. записів/клієнт**

## Управління користувачами (`/admin/users`)

### Перегляд
- Таблиця всіх користувачів: ім'я, email, роль, статус
- Фільтр за роллю (CLIENT / MASTER / ADMIN)

### Дії
| Дія | Кнопка | Наслідок |
|-----|--------|----------|
| Заблокувати | "Заблокувати" | Користувач не може увійти |
| Розблокувати | "Розблокувати" | Доступ відновлено |
| Видалити | 🗑️ | Безповоротне видалення |

### Створення акаунту майстра
1. Натисніть "Додати майстра"
2. Введіть ім'я, прізвище, email та пароль
3. Система автоматично призначає роль MASTER
4. Майстер отримує email з даними входу

## Управління послугами (`/admin/services`)

### Вкладка "Категорії"
- Перегляд усіх категорій (назва, опис, іконка emoji)
- **Додати категорію:** "Нова категорія" → назва + опис + іконка → "Зберегти"
- **Редагувати:** кнопка ✏️ → зміна назви/опису → "Зберегти"
- **Видалити:** кнопка 🗑️ → підтвердити

### Вкладка "Послуги"
- Список усіх послуг: назва, категорія, базова ціна, тривалість, статус
- **Додати послугу:** "Нова послуга" → назва, категорія, ціна, тривалість → "Зберегти"
- **Активація/деактивація:** перемикач "Активна" — деактивовані послуги не відображаються клієнтам
- **Редагувати / Видалити:** кнопки ✏️ / 🗑️

## Управління майстрами (`/admin/masters`)

- Grid-перегляд профілів майстрів: фото, ім'я, рейтинг, кількість записів
- **Заблокувати/Розблокувати** — без видалення акаунту
- Натисніть на майстра → деталі профілю, розклад, послуги
- Адмін може редагувати розклад будь-якого майстра (PATCH `/masters/:id/schedule`)

---

## Управління записами (`/admin/bookings`)

### Фільтри
- За статусом: Всі / Очікує / Підтверджено / Виконується / Завершено / Скасовано
- За датою: від / до
- За майстром і клієнтом (пошук)

### Дії
- **Підтвердити** — змінити статус PENDING → CONFIRMED
- **Скасувати** — з підтвердженням
- **Переглянути деталі** — повна інформація про запис

### Експорт CSV
- Кнопка "Експорт CSV" — завантажує поточний відфільтрований список записів

## Email-налаштування

У production системі налаштуйте SMTP в змінних середовища:
```
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USER=your@gmail.com
MAIL_PASS=app_password
MAIL_FROM=noreply@autoservice.com
```

Система автоматично надсилає:
- Підтвердження email при реєстрації
- Підтвердження запису
- Зміни статусу
- Скасування запису
- Нагадування за 24 і 2 години

## Технічне обслуговування

### Seed даних (перший запуск)
```bash
cd apps/backend && npm run seed
```
Створює: 3 тестових акаунти, 3 категорії, 9 послуг, 3 демо-записи.

### Бекап бази даних
```bash
mysqldump -u root -p autoservice > backup_$(date +%Y%m%d).sql
```

- Health check: GET `/api/v1/health`
- Swagger: GET `/api/v1/docs`
